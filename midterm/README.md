# RentKit

A student project for WEB Technologies 1.

RentKit is a website for a rental service that provides ready-to-use equipment kits for different tasks, including video production, podcast recording, movie nights, and presentations.

## How to Run

The website is located in the `midterm` folder.

Open:

`midterm/index.html`

in a browser or use Live Server.

No build process or dependency installation is required.

## Project Structure

Main pages:

- `midterm/index.html` — Home page
- `midterm/kits.html` — Equipment kits catalog
- `midterm/kit-details.html` — Detailed kit descriptions and prices
- `midterm/rent.html` — Rental process, conditions, and FAQ
- `midterm/order.html` — Demo order page

Additional files:

- `midterm/CREDITS.md` — sources for images, fonts, Bootstrap, and AI usage
- `midterm/css/` — website styles
- `midterm/js/` — JavaScript for the demo order page
- `midterm/images/` — images and SVG illustrations
- `midterm/fonts/` — local fonts
- `midterm/vendor/` — local Bootstrap files

## About the Project

The website has an English interface and is responsive for different screen sizes.

The project uses:

- semantic HTML
- Flexbox
- CSS Grid
- media queries
- Bootstrap
- forms
- a pricing table
- JavaScript for the demo order process

Rental prices, customer reviews, and booking information are fictional and are used only for demonstration purposes.

The order form does not send data to a server and does not process real bookings or payments.
