# RentKit

RentKit — учебная концепция бизнеса по аренде готовых комплектов оборудования. Посетитель выбирает задачу: снять видео, записать разговор, устроить киновечер или провести презентацию. Оборудование в модели принадлежит RentKit; предполагаемый доход — аренда и дополнительная доставка.

Аудитория: студенты, начинающие авторы, небольшие команды и люди, которым оборудование нужно ненадолго. Это концепция, а не подтверждённое исследование рынка. Сценарий обслуживания — Астана; реальный адрес и наличие оборудования не заявлены.

## Запуск

Откройте `midterm/index.html` в Chrome, Edge или Firefox. Также можно открыть папку репозитория в VS Code и запустить Live Server для этого файла. Сайт работает и по `file://`: скрипт не загружает данные через fetch. Bootstrap, шрифты и изображения сохранены локально; интернет при просмотре не требуется.

При установленном Python из корня репозитория можно выполнить `python -m http.server 8000`, затем открыть `http://localhost:8000/midterm/`.

Семантический HTML5, CSS custom properties, Flexbox, CSS Grid, собственные media queries, Bootstrap grid, карточки, кнопки, формы и таблица. FAQ работает через `details/summary`, меню всегда видно. Библиотека Bootstrap JavaScript не подключена: компонентов, требующих её, нет. React, Tailwind, backend и система сборки отсутствуют.

## Как работает заказ

Ссылки `order.html?kit=video`, `podcast`, `movie`, `presentation` выбирают соответствующий комплект. Неизвестный параметр оставляет обычный выбор. Изменение срока и получения обновляет пакетную цену. Дата не может быть раньше сегодняшнего дня в часовом поясе `Asia/Qyzylorda`.

Форма использует встроенную валидацию HTML и проверяет пробельное имя и дату. Кнопка изначально отключена и включается после регистрации обработчиков. `method="dialog"` у формы предотвращает сетевую отправку, в том числе без JS; поля контактов не имеют атрибута `name`. `noscript` объясняет ограничения. Скрипт не использует сеть, аналитику, localStorage, sessionStorage или логи. Подтверждение показывает только комплект, срок и сумму, без контактных данных. Изменение любого поля убирает старое подтверждение.
